# V1 이후 작업

## 기준본
- `v1.0.0`: 사용자 승인 디자인·본문. 태그를 이동하지 않는다.
- 후속 브랜치: `chore/v1.1-validation`.
- 2026-11-06 사용자 승인으로 저장소를 공개 전환했다. 기존 블로그와 Sites 미리보기는 변경하지 않는다.

## 이번 후속 작업
코드/Markdown 변경 시 GitHub Actions에서 문법 → 테스트 → 빌드 → 링크·초안 제외 검사를 수행한다. push, pull request, 수동 실행을 지원하며 배포 권한이나 쓰기 권한을 갖지 않는다. 새 글은 여전히 `draft: true`가 기본이고, CI 성공은 발행 승인이 아니다.

## 진행 중 — 2026-11-06
GitHub Pages 프로젝트 경로와 발행 흐름을 정비한다. 사용자 승인으로 공개 전환하고 Pages를 활성화했다. main 병합 후 Actions 배포 결과를 확인한다. [글 발행 절차](publishing.md)와 [콘텐츠 계획](content-roadmap.md)을 추가했다.

## 다음 선택
1. **배포**: GitHub Pages를 선택했다. main 병합 시 자동 배포되며 실제 URL, 상세 글, RSS, 깊은 경로의 404를 확인한다.
2. **글 이관**: 기존 글 목록·원본·URL 보존 범위를 정한 후, 초안으로 옮겨 링크/코드/공개 정보를 검수한다. 기존 블로그는 그대로 둔다.
3. **편집기**: 현재 로컬 전용 경계를 유지하며 실제 브라우저 저장·삭제·복구와 미저장 변경 경고를 추가 검수한다. 인증 없는 쓰기 API를 인터넷에 열지 않는다.
4. **자동화**: Codex는 초안 생성·검증까지, 외부 발행은 사용자 확인 후 실행한다. 예약 작업과 외부 API 연결은 별도 범위다.

디자인 개편이나 경력 문안 재작성은 이번 후속 작업에 포함하지 않는다.
