# 내용 설계와 출처

## 핵심 메시지
금융·제조·ML이라는 도메인의 변화보다, 실행 경로와 책임 경계를 이해하고 운영에서 확인하는 일관된 경험을 강조한다. 기술 숙련도 점수나 단순 경력 연수 합계로 대신하지 않는다.

## 레퍼런스에서 배운 구조 — 2026-11-04 재열람
- [이동욱](https://jojoldu.github.io/): 회사·역할·운영 경험의 연결. 경력 서술의 근거 링크.
- [최윤석](https://yunseokchoi.vercel.app/): 첫 화면에서 드러나는 개인의 관점과 프로젝트 탐색. 높은 인터랙션 밀도와 원문 디자인은 복제하지 않음.
- [이종민](https://jongminlee0.github.io/portfolio/): 프로젝트를 기술 문제로 나눠 상세 근거로 연결.
- [구태호](https://kootaeho.github.io/portfolio/): 정상 경로 외 실패와 상태 수명, 검증 범위.
- [조치호](https://www.chochiho.cloud/): 요약에서 문제·변경·결과의 상세 설명으로 이동.
이는 구성에 대한 편집 판단이다. 타인의 문장·실적·이미지·코드를 가져오지 않았다. 최윤석 PDF는 이번에 재열람하지 않고 사이트와 과거 로컬 조사 기록을 참고했다.

## 사실과 해석
공개 문안은 사용자의 로컬 경력 기록에 근거한다. 독립적인 성능 실측이나 재직 증명 검증은 아니다. 기록의 기준일 이후 성과나 인과관계를 추가하지 않는다. 고객사/실적의 외부 공개 승인 여부는 사용자 확인이 필요하다.

| 본문 | 근거 종류 | 유지할 경계 |
|---|---|---|
| 인증 캐시 | 2023.10~12 성능 개선 상세 경력, 기존 작성 기준 | Heap 10GB→3.5GB 기록; 동일 부하·평균/피크 미확인. GC rate 주장 금지. 정상/예외 정리 구분 |
| 금융 연동 | 2020.08~2021.06 혁신금융 상세 경력 | 2명 참여/40%, 조회 로직 약 95%. 180초는 응답 제한, 일 건수는 TPS 아님. 분산 원자성 주장 금지 |
| ML 운영 | 배포 자동화 성과 기록, 2026-08-10 신규 성과 기록 | 개발계 9개 CI/CD, 동기 4개 각10/10, 운영계 비동기 확인 분리. CI test stage는 후속 |
| 경력 | 직장별 요약 및 원천 | MDS 2017.04~18.04 / 다우 2018.10~24.06 / 현대오토에버 2024.06~현재. 전체 PL과 공통파트 PL 구분 |
| 경험 노트 | 위 실제 경험에서 재구성 | 새로 쓴 회고이며 기존에 발행된 블로그 글인 척하지 않음. 현재 점검 관점은 과거 완료와 분리 |

## 공개 전에
- 내부 주소·Jira 티켓·개인 전화번호·비공개 소스·고객 정보를 원문에 복사하지 않는다.
- 실제 덤프/로그/코드가 없다면 만들어 붙이지 않는다. 개념도는 개념도라고 표시한다.
- 사례는 회사·프로젝트·기간·본인 책임을 포함한다.
- 새 초안은 draft:true로 생성하고 외부 공개 전 내용과 기밀을 확인한다.
